## การแปลเงื่อนไขท้องถิ่นของภาพ (locality)

ภาพมีโครงสร้างท้องถิ่นคือจุดที่อยู่ใกล้กันมักมีส่วนร่วมสร้างลักษณะเดียวกัน เช่น เส้นขอบของวัตถุมักรวมกลุ่มอยู่เฉพาะที่ โมเดลจึงไม่จำเป็นต้องดูทั้งภาพพร้อมกันเพื่อจับลักษณะเล็ก ๆ ชั้นแรกของ CNN ใช้หน่วยขนาดเล็กเลื่อนผ่านภาพทีละตำแหน่งเพื่อบันทึกว่ามีลักษณะนั้นปรากฏที่ใดบ้าง
วิธีนี้ให้คุณสมบัติสำคัญคือผลลัพธ์ไม่ขึ้นกับตำแหน่งที่ลักษณะปรากฏโดยตรง เราเรียกว่า translation equivariance คือการเลื่อนตัววัตถุในภาพทำให้ feature map เลื่อนตามไปด้วยแต่ลักษณะที่รับรู้ยังเป็นลักษณะเดิม ความเข้าใจนี้ช่วยอธิบายว่าทำไม CNN รับรองรูปแบบเดียวกันได้แม้ตำแหน่งวัตถุจะเปลี่ยน
โครงสร้างท้องถิ่นยังลดจำนวนงานลงมากเพราะแต่ละตำแหน่งไม่ต้องเทียบกับทั้งภาพ การเชื่อมต่อระหว่าง pixel กับ neuron ถูกกำหนดให้อยู่ในพื้นที่แคบ ๆ แทนที่จะเชื่อมทุกจุดเข้าด้วยกัน นี่คือเทคนิคที่ทำให้ภาพขนาดใหญ่ประมวลผลได้จริงบนอุปกรณ์ปัจจุบัน
### สูตร: ขนาด output หลัง conv/pool

out = ⌊(input − kernel + 2·padding) / stride⌋ + 1

> input คือขนาดด้านของภาพหรือ feature map, kernel คือตัวกรอง, padding คือการเติมขอบ, stride คือระยะก้าวที่กระโดดในแต่ละตำแหน่ง

## convolution จริง: kernel, stride และ padding

Convolution คำนวณผลรวมถ่วงน้ำหนักของค่าที่อยู่ใต้ kernel ขนาดเล็กเช่น 3 ช่อง 3 ช่อง กับค่าภาพสุนทรนับหน่วยน้ำหนักของ kernel เองในแต่ละตำแหน่ง ความหมายของมันจึงไม่ใช่การบวกธรรมดา แต่เป็นการวัดว่า pattern ที่ kernel สนใจนั้นตรงกับภาพแค่ไหนในทุกตำแหน่งของภาพ
Stride คือระยะห่างที่ kernel กระโดดไปยังตำแหน่งถัดไป ค่า 1 หมายถึงเลื่อนทีละตำแหน่งเพื่อดูภาพละเอียด แต่ค่า 2 จะกระโดดสองตำแหน่งทำให้ภาพผลลัพธ์เล็กลงและคำนวณน้อยลง การเลือก stride เป็นการแลกความละเอียดกับการลดขนาดภาพ
Padding คือการเติมเลขขอบรอบภาพก่อนคำนวณ เพื่อให้ output ไม่หดเกินไปเมื่อใช้ kernel ใหญ่ เช่นภาพ 32 ช่อง 32 ช่อง ใช้ kernel 3 padding 1 stride 1 จะได้ output 32 ช่อง 32 ช่องเหมือนเดิม ตัวอย่างนี้ช่วยให้คำนวณขนาดก่อนเริ่มเขียนโครงสร้างเพื่อไม่ให้ชั้นใดชั้นหนึ่งหายไปโดยไม่รู้ตัว
**ตัวอย่าง — คำนวณแล้วจะเห็น trade-off**

ภาพ 32×32 + kernel 3, padding 1, stride 1 → ยังคงขนาด 32×32 เพราะ padding ชดเชยสิ่งที่ kernel ทับขอบ ถ้าใช้ stride 2 จะครึ่งขนาดเหลือประมาณ 16×16 แลกกับการคำนวณที่เร็วกว่ามาก

## การออกแบบชั้น CNN: conv, pooling, และลำดับชั้น

ลำดับชั้นทั่วไปเริ่มจาก conv เพื่อจับรายละเอียดและขอบ ต่อด้วย activation เพื่อเปิดทางความไม่เป็นเส้นตรง แล้วตามด้วย pooling หรือ stride 2 เพื่อลดขนาดการคำนวณและสงวนว่า feature ปรากฏหรือไม่ มากกว่าตำแหน่งที่แม่น วิธีนี้ทำซ้ำหลายครั้งจนได้ feature ที่เป็นรูปทรงระดับใหญ่ขึ้นเรื่อย ๆ
Pooling แบบ max ทดค่าน่าสงเกตสุดของแต่ละบล็อก หมายถึงการเก็บค่าสูงสุดของพื้นที่เล็ก ๆ ใน feature map นั่นทำให้ระบบทนต่อการเลื่อนตำแหน่งเล็ก ๆ ได้และประหยัดพื้นที่จัดเก็บข้อมูล ส่วน pooling แบบ average จะเก็บค่าเฉลี่ยของพื้นที่ แม้ว่าตำแหน่งของจุดจะสำคัญน้อยลงก็ยังให้ข้อมูลรวมที่เป็นประโยชน์ในบางงาน
โครงสร้างลึกทำให้ชั้นต้นจับขอบและมุมได้ดี ชั้นกลางจับรูปทรงได้ และชั้นลึกจับวัตถุเต็มชิ้นได้ แนวโน้มนี้ปรากฏในการ visualize activation ของโมเดลจริง ดังนั้นเมื่อออกแบบเราจึงไม่จำเป็นต้องทำให้ชั้นแรกใหญ่เกิน แต่ต้องให้โอกาสระบบค่อย ๆ สร้างความเข้าใจจากเล็กไปใหญ่

## receptive field และความสัมพันธ์ระยะไกล

Receptive field คือพื้นที่ของภาพต้นทางที่ neuron หนึ่งค่ามองเห็นได้ โดยการมองการคำนวณชั้นเดียวอาจเหลือเพียงพื้นที่ขนาด kernel แต่เมื่อซ้อนหลายชั้นพื้นที่รวมจะขยายใหญ่ขึ้นเรื่อย ๆ หมายความว่าชั้นลึกเห็นภาพกว้างกว่าแต่ไม่ได้เห็นทุกจุดพร้อมกันเหมือนภาพต้นฉบับ
ถ้าโจทย์ต้องการความสัมพันธ์ที่ไกลมากในภาพ เช่น ตัวอักษรสองตัวห่างกันนับสิบ pixel โมเดลต้องความลึกพอหรือใช้ dilation ที่ทำให้ kernel เว้นระยะดูภาพได้กว้างกว่าโดยไม่เพิ่มขนาด weight เท่าเดิม วิธีนี้เป็นทางเลือกเมื่อ depth เยอะเกินเกินไปจนเทรนไม่ไหว
ข้อจำกัดของ receptive field เป็นเหตุผลหนึ่งที่ Transformer ถูกนำมาใช้กับภาพในภายหลัง เพราะกลไก attention มองเห็น token ทุก token ได้โดยตรงและไม่ต้องไล่เงื่อนไขท้องถิ่นทีละขั้น การเลือกใช้ CNN หรือ Transformer จึงขึ้นกับว่าโครงสร้างท้องถิ่นหรือความสัมพันธ์ระยะไกลมีความสำคัญกว่ากัน
### สูตร: การสะสม receptive field

RF_l = RF_{l−1} + (k_l − 1) × jump_{l−1}   (jump = ความกว้างของการกระโดดรวมจาก stride ที่ผ่านมา)

> kernel ใหญ่และ stride รวมที่มากทำให้ RF ขยายเร็ว การคำนวณนี้ช่วยให้รู้ว่า neuron เห็นภาพต้นทางกว้างแค่ไหน

## weight sharing และจำนวนพารามิเตอร์

ตัวกรองตัวเดียวกันใช้ weight ชุดเดียวกันเลื่อนไปทั่วภาพและทุกช่องนั่นคือ weight sharing ซึ่งเป็นการใช้ประสบการณ์จากการตรวจจับ pattern ในตำแหน่งหนึ่งไปใช้กับตำแหน่งอื่น ๆ ระบบจึงไม่ต้องสร้างเครื่องมือใหม่สำหรับทุกตำแหน่งและเรียนรู้ลักษณะทั่วไปได้เร็วกว่า
จำนวนพารามิเตอร์ของชั้น conv คำนวณจากขนาด kernel คูณจำนวนช่องของ input แล้วคูณด้วยจำนวนตัวกรอง ส่วน dense layer ที่เชื่อมทุก pixel ทุก channel กับทุก neuron จะใช้จำนวนพารามิเตอร์มหาศาลกว่ามากตัวอย่างภาพเล็ก ๆ 32×32 กับ 3 channel ก็อายพารามิเตอร์ได้หลายแสนแล้ว
การที่ CNN ใช้พารามิเตอร์น้อยกว่านี้มันทำให้ภาพขนาดใหญ่ประมวลผลได้จริงและลดความเสี่ยง overfit แต่ trade-off คือโมเดลต้องพึ่งโครงสร้าง grid จึงเก่งกับภาพแต่ไม่เหมาะกับข้อมูลที่ไม่มีโครงสร้าง grid โดยตรง การเลือกโครงสร้างต้องสอดคล้องกับชนิดข้อมูลก่อนทุกอย่าง

## เมื่อใด CNN ถึง "ไม่ใช่คำตอบ" และแนวทางที่เหลือ

CNN เกิดจาก induction bias ของภาพคือมองว่า feature ที่อยู่ใกล้กันใช้หลักเดียวกันได้ เมื่อข้อมูลไม่ได้อยู่บน grid เช่น กราฟหรือกลุ่มจุดสามมิติ induction bias นั้นไม่สอดคล้องกับโครงสร้างจริงของข้อมูล จึงต้องใช้สถาปัตยกรรมที่ออกแบบให้ตรงกับข้อมูลเหล่านั้นแทนการฝืนใช้ CNN
ถ้าโจทย์ต้องการความสัมพันธ์ช่วงไกลหรือความละเอียดสูง การเพิ่ม depth เรื่อย ๆ ทำให้เทรนยากและการคำนวณสูงเกิน จนอาจกลายเป็นจุดที่ควรพิจารณา attention แทน การตัดสินใจต้องเริ่มจากคำถามว่าข้อมูลต้องการมองไกลแค่ไหน ไม่ใช่เพียงติดตามความนิยมของโครงสร้าง
เมื่อข้อมูลน้อยมากและต้องอธิบายเหตุผล การใช้ CNN ผ่าน dataset ขนาดเล็กอาจ overfit ง่ายและไม่สอดคล้องกับตลาดจริง วิธีเช่น Grad-CAM หรือ LIME ช่วยอธิบายบางส่วนของการตัดสินใจ แต่ไม่ได้ทำให้โมเดลเข้าใจและสอดคล้องเสมอไป นั่นคือข้อจำกัดที่ต้องยอมรับก่อนนำไปใช้งานจริง
