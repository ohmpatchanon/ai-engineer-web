## ภาพรวม: computational graph คือแผนที่ของ backprop

Computational graph คือภาพของการคำนวณที่ต่อกันเป็นลูกโซ่ซึ่งแสดงว่าแต่ละค่าเป็นผลของการคำนวณขั้นตอนก่อนหน้าอย่างไร โดยแต่ละ node คำนวณค่าของตัวเองจาก input และเก็บ derivative ของตัวเองพอแล้วจึงค่อยส่งต่อไป ถ้าเราเข้าใจตารางนี้ก็คือเข้าใจว่า backprop จะวิ่งกลับไปหา parameter ที่มีส่วนร่วมได้อย่างไร
ทิศทาง forward คำนวณค่าจาก input ไปยัง output ทีละขั้น ส่วนทิศทาง backward ส่ง gradient จาก output กลับไปที่ input และ parameter ที่เชื่อมอยู่ระหว่างกัน ระบบคำนวณเพื่อหาว่าแต่ค่าใดมีผลต่อ loss มากเพียงใด และแต่ละ parameter ควรขยับไปทางใดจึงจะลด loss ลง
การเรียนรู้แบบ gradient วางอยู่บนสมมติฐานว่าโมเดลเป็น composition ของฟังก์ชันหลายชั้นที่คูณกันไปเรื่อย ๆ หากเกิด derivative ใดใกล้ศูนย์หรือใกล้ค่ามหาศาล ความผิดพลาดจะขยายตัวหรือหดตัวไปตามเพลงนั้นในทันที นี่คือที่มาของปัญหา vanishing และ exploding gradient ที่มักปรากฏในโครงสร้างลึก

## chain rule ที่วิ่งย้อนกลับทีละขั้น

Chain rule กล่าวว่า derivative ของฟังก์ชันประกอบกันสามารถคำนวณได้จากการคูณ derivative ของฟังก์ชันส่วนประกอบทีละขั้น backprop ใช้กฎนี้โดยเริ่มจากปลายทางซึ่งเป็น loss แล้วคูณ derivative ของการคำนวณก่อนหน้ากลับไปทีละขั้นตามลำดับ reverse order หมายความว่าแต่ละ parameter คือผลคูณของ derivative เป็นเส้นตรงไปถึงชั้นก่อนหน้า
การคำนวณย้อนกลับมีข้อดีทำให้ไม่ต้องคำนวณอ้วนออก เพราะแต่ละขั้นหนึ่ง ๆ คิดผลคูณใหม่จากค่าที่เพิ่งได้มา เปรียบเสมือนเรามองจากปลายของเชือกดึงแล้วถามว่าเชือกสามารถคลายไปได้อย่างไรบ้าง ซึ่งสอดคล้องกับวิธี forward pass ที่ไล่จากต้นจนจบ
เมื่อทุก parameter ได้ค่า gradient ของตัวเองแล้วระบบจะคำนวณค่าก้าวของแต่ละตัวจาก optimal ต้องใช้สัญญาณ gradient ในทิศที่ถูกต้องและมีขนาดพอเหมาะ หากการประเมินสัญญาณผิดพลาด ทิศทางของโมเดลจะไม่ไปสู่จุดที่ดีกว่า และการเทรนจะกลายเป็นไม่เสถียร
### สูตร: chain rule พื้นฐานของ backprop

dL/dw = dL/dy × dy/dw   (L = loss, w = parameter, y = ค่าของชั้นที่เชื่อมกับ parameter นั้น)

> เราคูณ derivative ทีละขั้นตามลำดับชั้นที่คำนวณไล่จากปลายกลับไปต้น ถ้ามี derivative ขั้นใดใกล้ศูนย์ผลคูณรวมจะใกล้ศูนย์ไปด้วย

## vanishing gradient: ทำไมยิ่งลึกยิ่งหาย

Vanishing gradient เกิดขึ้นเมื่อ derivative หลายขั้นมีค่าที่น้อยกว่าหนึ่งและถูกคูณกันซ้ำไปเรื่อย ๆ เช่น 0.5 คูณ 0.5 กี่ครั้งก็ยิ่งเข้าใกล้ศูนย์มากขึ้นเรื่อย ๆ สาเหตุที่เกิดได้บ่อยคือการใช้อActivation ที่อิ่มตัวได้ง่ายเช่น sigmoid หรือ tanh และการเริ่มต้น weight ที่มีค่าเล็กจนสัญญาณหดตัวเมื่อไล่ย้อนกลับ
ผลลัพธ์คือชั้นที่ลึกจะแทบไม่ขยับตัวเลยแต่ชั้นสุดท้ายยังคงเรียนรู้ได้ การเทรนระบบต้องเผื่อเวลาและ υπολογισตรึงรอให้ชั้นลึกขยับแต่จำนวนรอบนั้นเป็นไปไม่ได้เพราะ derivative หายไปหมดก่อนถึงชั้นเหล่านั้น นี่จึงเป็นปัญหาที่ยิ่งรูปแบบลึกยิ่งชัดในประวัติศาสตร์ของ deep learning
วิธีแก้ vanishing gradient ต้องลดความเสี่ยงตั้งแต่ต้นด้วยการเริ่มต้น weight ที่สเกลตาม fan-in เช่น Xavier และ He และใช้ activation ที่ส่ง gradient ได้ดีอย่าง ReLU ควบคู่กับการใช้ residual connection ที่ให้ pathway ไปถึงโดยตรงโดยไม่ต้องผ่านชั้นกลางหลายชั้น

## exploding gradient: เมื่อ gradient ระเบิด

Exploding gradient เกิดเมื่อ derivative หลายขั้นมีค่ามากกว่าหนึ่งและถูกคูณกันหลายครั้ง เช่น 2 คูณ 2 ทีละครั้งจะยิ่งโตอย่างรวดเร็ว อาการจะเห็นในโครงสร้างที่ซ้อนหลายชั้นโดยไม่ควบคุม weight หรือลำดับชั้นที่ไม่เหมาะสม ทำให้ระบบขยับอย่างไม่แน่นอนและห่างจากคำตอบเดิมอย่างมาก
เมื่อ gradient มีขนาดเกิน ทำให้เกิดความล้มเหลวในการควบคุมทิศทางและทำให้การเทรนไม่เสถียร วิธีที่เข้ากันได้ในการแก้คือการ clipping gradient โดยตัดขนาดที่เกินขีดจำกัดออกก่อนที่จะปรับ parameter วิธีนี้ทำให้การขยับไม่ใหญ่มากจนทำให้ระบบเสียเสถียรภาพมากมาย
สังเกตว่า vanishing กับ exploding เป็นปัญหาที่พบในโมเดล RNN บ่อยในช่วงแรก ๆ ของการพัฒนาของ เพราะลำดับเวลาที่ต้องคูณ derivative ซ้ำกันหลายครั้งผ่านขั้นตอนเวลาหลายพันขั้น แต่ก็เกิดขึ้นกับโมเดลลึกได้เช่นกันเมื่อโครงสร้างเป็นการซ้อนหลายชั้นโดยไม่มีการควบคุมสัญญาณที่เหมาะสม

## วิธีแก้ที่นิยม: init, normalization, residual และ clip

วิธีแก้มาตรฐานครอบคลุมหลายด้านตั้งแต่ก่อนเทรนและการวัด gradient เริ่มจาก weight init ที่สเกลตาม fan-in เช่น Xavier หรือ He เพื่อให้ variance ของสัญญาณคงที่เมื่อผ่านไปกลับในแต่ละชั้น จากนั้นก็ต้อง normalization เช่น Batch Norm หรือ Layer Norm เพื่อลดการกระจายตัวของสัญญาณให้สม่ำเสมอขึ้น
Residual connection เป็นวิธีแก้ด้วยโครงสร้างที่เพิ่ม pathway ตรงไปสู่ปลายทางโดยไม่ผ่านหลายชั้นซึ่งทำให้ gradient ไหลได้โดยตรงไม่ต้องคูณ derivative เป็นพักทำให้ gradient หายเมื่อผ่านชั้นกลาง นี่คือโครงสร้างที่เปิดโอกาสให้โมเดลลึกในประวัติศาสตร์ได้ และเป็นหลักของชุมชน neural network ในปัจจุบัน
การ clip gradient เป็นมาตรการป้องกันที่ง่ายโดยการจำกัดขนาด gradient ตันอัตโนมัติเมื่อขนาดเกินค่าที่กำหนด วิธีนี้เป็นที่นิยมเพราะบริหารง่ายและทำได้ทันทีโดยไม่ต้องเปลี่ยนสถาปัตยกรรม แต่ต้องตั้งค่า threshold ให้เหมาะสมกับงาน ไม่เช่นนั้นจะกด gradient มากเกินไปจนทำให้เทรนช้าลง
เหล่านี้สรุปเป็นสิ่งที่ควรทำก่อนเสมอคือการประเมินประสิทธิภาพสูญเสียให้ดีก่อนการขยายโครงสร้าง หากโครงสร้างเดิมยังฝึกไม่ได้ดี จะไม่มีชื่ออ่างว่าตัวโครงสร้างใหม่จะแก้ปัญหาอะไรได้ ความสามารถในการวัด gradient ให้มีความหมายทำให้การเทรนเป็นไปอย่างมีเหตุผลมากกว่าการรอโชค

## ฝึกความเข้าใจ gradient ด้วยกราฟเล็ก ๆ

การไล่การคำนวณด้วยมือบนกราฟเล็ก ๆ ทำให้เข้าใจหลักการของ backprop ได้ลึกกว่าแค่อ่านสูตร เพราะเห็นได้ว่าการคูณ derivative ทีละขั้นจากปลายกลับไปต้นทำให้ parameter ตัวแรกสุดมีค่าที่เป็นผลคูณของทุกชั้นที่อยู่ระหว่างนั้น การลงมือเขียนคำนวณด้วยมือครั้งหนึ่งทำให้โมเดลความเข้าใจเชิงภาพมีน้ำหนักมากขึ้น
ในกราฟตัวอย่างเล็ก ๆ ที่มีเครื่องคิดเลขสามขั้น เราจะเห็นว่าแต่ละขั้นเกี่ยวข้องกับ parameter ที่อยู่ถัดจากกันอย่างไร และถามคำถามว่าจะปรับ parameter ตัวใดเพื่อให้ loss ลดลงมากที่สุด จึงเป็นวิธีเรียนรู้ที่เปิด mental model ของการคำนวณ backprop จากสูตรนามธรรมสู่ภาพการคำนวณที่เป็นรูปธรรม
การฝึกกับกราฟเล็กๆเช่นแบบนี้ทำให้เวลาเจอโมเดลใหญ่ไม่รู้สึกว่าแปลก เพราะโมเดลใหญ่ประกอบด้วยกราฟเล็กหลายสิบกราฟคูณกันอย่างเดียวกัน การลดความซับซ้อนพิสูจน์ให้เห็นว่ามีหลักการเดียวกันที่ใช้ได้กับทุกขนาดของกราฟในชีวิตจริง

## อ่าน gradient diagnostics ตอนเทรนจริง

ในการเทรนจริงการติดตามขนาดของ gradient เป็นสัญญาณสำคัญบอกว่าโมเดลกำลังเรียนรู้ดีหรือไม่ ถ้า gradient หายไปใกล้ศูนย์อย่างรวดเร็วแต่ train ไม่ได้ดีขึ้นอาจเป็นสัญญาณของ vanishing gradient แต่ถ้า gradient โตขึ้นเร็วจนคุมไม่อยู่ อาจเป็น exploding gradient และทำให้การคอนโทลการเทรนเสียไป
การตรวจ norm ของ gradient ในแต่ละ layer ทำให้รู้ได้ว่าชั้นใดไม่ขยับหรือขยับมากเกิน ก่อนตัดสินใจต้องดูว่า gradient นั้นเล็กหรือใหญ่เพราะสาเหตุอะไรเช่น init ผิดแล้วค่อยแก้ตามสาเหตุ ถ้า gradient ของชั้นเล็กจังหวะมากกว่าชั้นใหญ่ ก็ไม่ควรเพิ่มชั้นไปซ้ำอีกเพราะจะทำให้ flushing แย่กว่าเดิม
เครื่องมือเรียนรู้มาตรฐานที่ผ่านสู่ practice จริงคือการ clip gradient เพื่อป้องกันการระเบิดและดู norm ของ gradient ที่แต่ละชั้น วิธีเหล่านี้เสริมซึ่งกันและกัน และทำให้ระบบสามารถฝึกได้เสถียรแม้ในโครงสร้างที่ลึกและมีข้อมูลซับซ้อน
> [!DIAGNOSE FIRST]
> ก่อนแก้ vanishing/exploding ให้ดู norm ของ gradient ทีละ layer และดูว่า input normalization ถูกต้องหรือไม่ การ clip เป็นการกันไว้เท่านั้น ไม่ได้แก้ต้นเหตุของ gradient ที่พัง
